# VoxSekai

VoxSekai – музыкальный каталог с серверным рендерингом, встроенным аудиоплеером, пользовательскими аккаунтами и админ-панелью. Приложение работает на Express и EJS, а каталог, пользователи и оценки хранятся в SQLite.

## Возможности

### Для слушателей

- каталог треков с поиском, фильтрацией по жанрам и сортировкой;
- страницы исполнителей, подборок, событий и публичных плейлистов;
- аудиоплеер с очередью, перемоткой, регулировкой громкости и переходом между треками;
- регистрация и вход по имени пользователя или e-mail;
- оценки треков по пятибалльной шкале;
- избранное, личные плейлисты и краткая статистика музыкальных предпочтений;
- адаптивная верстка для компьютеров и мобильных устройств.

### Для администратора

- управление треками и исполнителями;
- создание подборок, плейлистов и событий;
- привязка треков к исполнителям, подборкам и плейлистам;
- загрузка обложек и аудиофайлов или подключение файлов по URL;
- настройка цветовых стилей карточек;
- просмотр и создание пользователей.

## Стек

- [Node.js](https://nodejs.org/) 20 или новее;
- [Express](https://expressjs.com/);
- [EJS](https://ejs.co/);
- [SQLite](https://www.sqlite.org/) через `better-sqlite3`;
- `express-session` для сессий;
- `Multer` для загрузки файлов;
- обычные CSS и JavaScript без клиентского фреймворка и этапа сборки.

## Быстрый запуск

### Через npm

```bash
git clone <repository-url>
cd voxsekai
npm ci
npm start
```

Откройте [http://localhost:3001](http://localhost:3001). База данных и недостающие таблицы создаются автоматически при первом запуске.

### В Windows

Запустите `start.bat` двойным щелчком. Скрипт откроет меню, из которого можно:

1. установить зависимости и запустить сервер;
2. остановить сервер;
3. перезапустить сервер;
4. переустановить зависимости;
5. установить или сбросить демонстрационную базу;
6. вернуть оригинальную базу;
7. очистить оригинальную базу, не затрагивая демонстрационную.

Те же действия доступны из командной строки:

```bat
start.bat start
start.bat stop
start.bat restart
start.bat install
start.bat use-demo
start.bat restore-db
start.bat clear-db
```

Для переключения и очистки базы сервер должен быть остановлен. `clear-db`
запрашивает подтверждение словом `CLEAR`; для подтверждённого запуска без
диалога можно использовать `start.bat clear-db --yes`. Команды управления базой
работают с `db/voxsekai.db`; перед их использованием временно сбросьте
переменную `VOXSEKAI_DB`, если она задана.

## Админ-панель

Админ-панель доступна по адресу [http://localhost:3001/admin](http://localhost:3001/admin).

Учетная запись для локального запуска создается автоматически:

```text
Логин: Yoshimru
Пароль: adminadmin
```

> [!WARNING]
> Эти учетные данные и ключ сессии заданы в исходном коде для локальной разработки. Перед публикацией приложения замените их и вынесите секреты в переменные окружения.

Свежая база содержит схему, стандартные стили карточек и учетную запись администратора. Наполнить каталог можно через админ-панель.

## Настройка

Приложение читает параметры напрямую из переменных окружения. Файл `.env` автоматически не загружается.

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3001` | Порт HTTP-сервера |
| `VOXSEKAI_DB` | `db/voxsekai.db` | Путь к файлу SQLite |

Пример для PowerShell:

```powershell
$env:PORT = "4000"
$env:VOXSEKAI_DB = "C:\data\voxsekai.db"
npm start
```

Пример для Bash:

```bash
PORT=4000 VOXSEKAI_DB=./data/voxsekai.db npm start
```

## Где хранятся данные

| Данные | Хранилище |
| --- | --- |
| Треки, исполнители, подборки, события и публичные плейлисты | SQLite |
| Пользователи и оценки треков | SQLite |
| Загруженные обложки и аудио | `assets/uploads/` |
| Избранное и личные плейлисты слушателя | `localStorage` браузера |
| Настройки профиля и состояние плеера | `localStorage` браузера |

Рабочие SQLite-файлы, загруженные медиа и `node_modules` исключены из Git. Исключение — шаблон
демонстрационной базы `db/demo/voxsekai-demo.db`, который хранится в репозитории.
При переносе собственных рабочих данных их нужно копировать отдельно.

### Ограничения загрузки

- изображения: JPG, PNG, WEBP, GIF или AVIF, до 6 МБ;
- аудио: MP3, WAV, OGG, M4A, FLAC или WEBM, до 30 МБ.

## Работа с базой данных

При запуске приложение:

1. открывает файл, указанный в `VOXSEKAI_DB`;
2. включает внешние ключи и режим WAL;
3. применяет `db/schema.sql`;
4. выполняет встроенные миграции недостающих столбцов;
5. добавляет стандартные стили, если соответствующие таблицы пусты.

Чтобы начать с чистой оригинальной базы, остановите сервер и выберите
`Clear ORIGINAL database` в `start.bat`. При следующем запуске база будет создана
заново. В отличие от ручного удаления файлов эта команда учитывает включённый
демо-режим и не удаляет демонстрационную базу.

### Демонстрационная база

Шаблон `db/demo/voxsekai-demo.db` содержит 8 популярных виртуальных исполнителей и
16 треков — не менее двух треков для каждого исполнителя. В каталог входят Hatsune Miku,
Kagamine Rin, Kagamine Len, Megurine Luka, KAITO, MEIKO, GUMI и Kasane Teto. В базу
также добавлены 5 вымышленных демонстрационных событий, подборка и публичный плейлист.
Аудиофайлы известных композиций не включены, потому что не удалось подтвердить свободную
лицензию, разрешающую распространять их копии через Git.

При выборе `Install/reset demo database` скрипт:

1. сохраняет текущую рабочую базу в локальный каталог `db/runtime/`;
2. копирует отслеживаемый шаблон на место `db/voxsekai.db`;
3. при повторном выборе сбрасывает демо-базу до исходного состояния.

`Restore original database` возвращает сохранённый файл. Команда очистки всегда удаляет
только оригинальную базу: если демо-режим активен, очищается резервная копия, а активная
демо-база и её шаблон остаются без изменений.

После редактирования `data/demoCatalog.js` шаблон можно пересобрать командой:

```bash
npm run demo:build
```

## Разработка

Отдельного этапа сборки нет: после изменения серверного кода или EJS-шаблонов перезапустите приложение. Изменения CSS и клиентского JavaScript достаточно обновить в браузере.

```bash
npm start
```

Полноценный регрессионный набор тестов и линтер в проекте пока не настроены.

Для воспроизведения функциональной проверки из отчёта выполните:

```bash
npm run test:report
```

Набор запускает 15 интеграционных тестов на временной SQLite-базе и не изменяет рабочие данные. Подробные тест-кейсы и результаты находятся в [`TEST_REPORT.md`](TEST_REPORT.md).
